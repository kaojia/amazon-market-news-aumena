# Amazon Market News AU/MENA/EU

Cross-border e-commerce intelligence site — automatically compiles daily news for AU / AE / SA and Europe (UK, DE, FR, IT, ES, NL, PL, SE, BE, IE).

🔗 **Site: https://kaojia.github.io/amazon-market-news-aumena/**

---

## Site features

- 📰 Daily news cards with a summary, impact analysis for Amazon sellers, suggested actions, and the original source link
- 🏷️ Category filters: tax, compliance, macro, logistics, trade, geopolitics, platform
- 🔍 Full-text search
- 📱 Responsive design (desktop / tablet / phone)
- 📅 Sidebar: key-date overview + Amazon AU/MENA major sale events

---

## How it works

```
reports/daily-report-*.html  →  build.py  →  index.html  →  GitHub Pages
      (daily report data)        (parse & inject)  (site page)    (auto deploy)
```

### Structure

| File | Purpose |
|------|---------|
| `reports/daily-report-YYYY-MM-DD.html` | Daily news report (HTML with news cards) |
| `index.html` | Site home page (template + data, generated by the build script) |
| `scripts/build.py` | Python build script; scans all daily reports and injects the data into `index.html` |
| `.github/workflows/build.yml` | GitHub Actions CI/CD; builds and deploys automatically |

### Automated flow

1. **Add a daily report**: put `reports/daily-report-YYYY-MM-DD.html` in the `reports/` folder
2. **Push to main**: `git add` → `git commit` → `git push`
3. **GitHub Actions runs automatically**:
   - Runs `python scripts/build.py`
   - The script scans every `reports/daily-report-*.html` and parses each news card
   - The parsed result (JSON) is injected into the `/*__ARTICLES_JSON__*/` placeholder in `index.html`
   - The updated `index.html` is committed automatically
   - Deployed to GitHub Pages

### build.py parsing logic

- Uses the Python standard library `html.parser` (zero dependencies)
- Extracts from each `.card` div: title, summary, impact analysis, suggested action, source link, priority
- Maps report keywords to site tags automatically (the site's tags are displayed in Chinese):

| Report keywords | Site tag |
|-----------------|----------|
| Supply chain, logistics | Logistics (物流), Geopolitics (地緣政治) |
| Macro, interest rates, consumption | Macro (總經) |
| Tax, VAT, e-invoicing | Tax (稅務) |
| Regulation, consumer protection, AML | Compliance (合規) |
| Trade, tariffs | Trade (貿易) |
| E-commerce market, competition | Platform (平台) |

- Priority colors: 🔴 high → `#dc2626`, 🟡 medium → `#f59e0b`, 🔵 default → `#0369a1`

## AI Pulse — daily AI industry news

🔗 **Site: https://kaojia.github.io/amazon-market-news-aumena/ai-news/**

A separate page tracking AI industry news, with 3–5 key AI stories selected each day across LLMs, chips, policy, startups, and research.

### How it works

```
ai-news/ai-report-*.json  →  ai-news/build.py  →  ai-news/data.js  →  ai-news/index.html
     (daily news JSON)          (merge script)        (front-end data)     (site page)
```

### Updating

```bash
# 1. Create ai-news/ai-report-YYYY-MM-DD.json
# 2. Run the build
python ai-news/build.py    # run from the ai-news/ directory

# 3. Push
git add ai-news/
git commit -m "AI Pulse: add daily news YYYY-MM-DD"
git push
```
